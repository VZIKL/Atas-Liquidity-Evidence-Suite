# HorizontalLine

**完整名称**: `ATAS.Indicators.Drawing.HorizontalLine`
**类型**: 类

## 描述

Represents a horizontal line on a chart.

## 属性

  - `decimal Price { set; }`
    - Gets or sets the price level of the horizontal line.
  - `int Width { set; }`
    - Gets or sets the width of the horizontal line.
  - `DashStyle Style { set; }`
    - Gets or sets the dash style of the horizontal line.
  - `Color Color { set; }`
    - Gets or sets the color of the horizontal line.
