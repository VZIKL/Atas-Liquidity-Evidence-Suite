# ExtendedIndicator

**完整名称**: `ATAS.Indicators.ExtendedIndicator`
**类型**: 类
**继承自**: `ATAS.Indicators.BaseIndicator`

## 描述

An extended base class for custom indicators that provide additional functionality for drawing, alerts, market data handling, etc.
